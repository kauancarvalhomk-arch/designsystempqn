# Typography Design System

## Font Family
All styles use **Inter** as the primary font family.  
Body styles also support **Be Vietnam Pro** as an alternative family.

## Summary of Rules

- **Display**: Font size 32–72px, weight Extrabold only, line height 110%, letter spacing 1
- **Heading**: Font size 16–32px, weights Extrabold/Bold/Semibold, line height 100%, letter spacing 0
- **Body**: Font size 12–20px, weights Bold/Semibold/Medium/Regular, line height 100%, letter spacing 0
